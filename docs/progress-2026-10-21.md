## Rekonsiliasi snapshot condition B

Checker dan baseline condition B direkonsiliasi terhadap snapshot yang ditetapkan. Isi salinan indeks diperiksa tanpa mengubah sumber. Receipt mengikat corpus, source lock, enam hash indeks, konfigurasi embedding, dan bukti pemeriksaan. Baseline tidak diganti untuk membuat checker lolos.

## Pilot perbandingan B dan C, S1 Low

Pilot baru menjalankan DVWA S1 Low untuk SQL injection error-based, satu replikasi, sepuluh kandidat per kondisi, dan tiga konfirmasi per kandidat.

- **B, Qwen 3.8 API dengan RAG aktif:** sepuluh kandidat valid, tiga sukses terkonfirmasi dan tujuh negatif. Recovery memakai 20 request API. Satu request pada attempt awal menghasilkan format kandidat invalid sebelum probe kandidat; total penggunaan lintas dua attempt adalah 21 request API. Peneliti kemudian mengonfirmasi seluruh sepuluh label setelah membaca laporan.
- **C, SecLists:** sepuluh kandidat unik, dua sukses terkonfirmasi dan delapan negatif. Tidak ada request API. Peneliti mengonfirmasi seluruh sepuluh label setelah membaca laporan.

Konfirmasi peneliti merupakan review setelah laporan terlihat, bukan anotasi blind VAL-01. Receipt as-run tetap menyimpan status validasi saat eksekusi. Setiap run melakukan reset database DVWA dan mencatat 60 logical probe submissions.

## Batas interpretasi dan status

Hasil B sebesar 3/10 dan C sebesar 2/10 adalah hitungan pilot deskriptif. Cakupan hanya satu skenario, satu level, dan satu replikasi. Hasil ini tidak menetapkan keunggulan sumber kandidat dan tidak dihitung sebagai PSR formal. Status `formal_psr` tetap `null`, dan pilot ini bukan eksekusi formal.

Catatan insiden B menyebut temuan credential pada helper dan menyatakan status rotasi API key belum terverifikasi. Nilai credential tidak dimasukkan ke artefak progres. File hasil mentah tetap berada di `results/raw/` yang dikecualikan dari Git sesuai `.gitignore`; receipt dan laporan menyimpan hash bukti terkait.

## Persiapan evaluasi kompetensi Qwen API P2

Pada 21 Oktober, peneliti melaporkan pembimbing setuju mencoba API LLM. Persetujuan mencoba ini dicatat sebagai keputusan penelitian untuk melanjutkan evaluasi API, bukan persetujuan formal amendemen proposal.

Diagnosis terdahulu pada 36 kasus eligible dan enam input invalid sudah tersedia dari 20 Oktober. Diagnosis tidak diulang. Kontrak analisis v2 tanpa RAG kini dibekukan untuk set evaluasi baru dengan batas keluaran 2048 token dan timeout 90 detik. Bukti yang dipakai berasal dari snapshot U06 v15; loader memeriksa hash artefak sumber tanpa menulis ulang sumber.

Paket pemeriksa independen berisi 18 kasus baru yang seimbang untuk error-based, boolean-based blind, dan time-based blind. Masing-masing teknik memiliki dua kasus sampling positive, dua negative, dan dua inconclusive. Lima kasus inconclusive menghilangkan satu trial utuh secara terkendali; satu kasus time-based lainnya adalah bukti mixed alami. Enam kasus gate invalid, satu runtime dan satu baseline invalid per teknik, semuanya tertahan sebelum API. Paket blind tidak memuat run, skenario, kondisi, payload, strata sampling, atau klaim model. Metadata sumber serta peta sampling disimpan terpisah.

**Status:** Semua 18 request telah diproses. Empat respons tidak tersedia: tiga request dari proses yang terputus dan satu timeout transport 90 detik tanpa respons HTTP. Keempatnya ditandai belum pasti dan tidak dikirim ulang. Empat belas respons berhasil diparse.

Pada 14 kasus yang dapat dinilai, keputusan Qwen cocok dengan label review independen pada 14/14 kasus. Cakupan terhadap seluruh paket 14/18 atau 77,8 persen. Cakupan per teknik adalah error-based 5/6, boolean-based blind 5/6, dan time-based blind 4/6; semua kasus terjawab cocok dengan label reviewer. Kasus tidak tersedia dikeluarkan dari penyebut agreement, bukan dianggap benar atau salah. Ini hasil pengembangan P2, bukan FPR/PSR formal dan bukan hasil PSR payload.

- Paket untuk pemeriksa: `results/raw/development/qwen38-api-p2-eval-20261021-ready/validator/packets.json`
- Instruksi dan template: `results/raw/development/qwen38-api-p2-eval-20261021-ready/validator/INSTRUCTIONS.md` dan `annotations.template.csv`
- Ringkasan respons API: `results/raw/development/qwen38-api-p2-eval-20261021-run-001/evaluation-results.json`
- Agreement dengan label reviewer: `results/raw/development/qwen38-api-p2-eval-20261021-run-001/evaluation-assessment.json`
- Skrip persiapan dan assessment: `development/prepare_qwen_api_p2_eval.py` dan `development/assess_qwen_api_p2_results.py`
- Status run: `completed_with_ambiguity`; raw responses dan label terkunci tetap berada di `results/raw/` yang dikecualikan dari Git.

**Kemajuan P2: 80% menuju penutupan.** Estimasi ini memakai lima gerbang kerja dengan bobot sama: diagnosis lama, pembekuan kontrak dan paket, penguncian label independen, eksekusi serta assessment, lalu keputusan peneliti atas batas hasil. Empat gerbang pertama selesai; keputusan peneliti masih diperlukan untuk menutup P2 dengan empat kasus belum terselesaikan atau menyetujui addendum terpisah. Persentase kemajuan ini berbeda dari cakupan data 77,8 persen dan bukan FPR/PSR.

**Tindakan lanjutan:** tinjau empat kasus tanpa respons, catat keputusan tanpa mengirim ulang ID yang sama, lalu bekukan assessment P2. Sesudah itu lanjut ke P3: audit generasi dan deduplikasi kandidat API, jalankan smoke generation terisolasi, kemudian siapkan matriks pilot A/B dan C dengan batas API dan pengukuran HTTP SQLi yang tercatat terpisah.
