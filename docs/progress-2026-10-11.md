## Hasil

Review teknis sembilan entri korpus selesai. Qwen lokal menghasilkan satu pasangan S1 RAG-off/on dengan konfigurasi sama. Keduanya dieksekusi satu replikasi pada DVWA Low dan memunculkan SQL error baru dibandingkan baseline normal. Ini bukti integrasi komponen lokal, belum eksperimen formal atau bukti peningkatan FPR/PSR.

Review awal proyek disimpan di `review-progress-2026-10-11.md`; dokumen ini mencatat pekerjaan lanjutan setelah review tersebut. Hasil review per entri ada di `corpus-review-2026-10-11.md`, ringkasan bukti di `evidence/progress-2026-10-11.json`.

## Review korpus

- Sumber dikunci: OWASP WSTG v4.2 dan PayloadsAllTheThings SQL Injection.
- Sembilan entri, tiga per teknik; schema, hash snapshot, heading dan rujukan baris lulus validasi.
- Tidak ada koreksi isi yang wajib untuk smoke S1. Hash korpus dan index aktif tetap sama.
- Review dilakukan oleh Codex; `researcher_review` tetap `pending` sampai peneliti menyatakan keputusan.
- Definisi keberhasilan error-based pada smoke ini adalah sinyal SQL error baru. Hal tersebut belum membuktikan ekstraksi data; definisi PSR formal perlu disepakati.

## Pengamatan injection point

Login serta level Low diverifikasi pada sesi HTTP yang sama. Form HTML aktual pada `/vulnerabilities/sqli/` memakai GET dan field `id`, `Submit`. Baseline `id=1` menghasilkan record dan tidak mengandung diagnostik SQL yang dicatat.

Pengamatan ini diberi sumber `authenticated-http-form-smoke`. Generasi tetap menggunakan konteks katalog dengan provenance `scenario-catalog-smoke`; pengamatan form setelah generasi mengonfirmasi kecocokan koordinat. Ini tidak menggantikan discovery ZAP formal. Report normalized ZAP Low sebelumnya masih tidak memiliki kandidat yang cocok.

## Hasil generasi dan validasi

| Ukuran | RAG-off | RAG-on |
| --- | --- | --- |

| Durasi load model | 11,59 detik | 0,02 detik |
| Status akhir model | stop; JSON valid | stop; JSON valid |
| Baseline / kandidat HTTP | 200 / 200 | 200 / 200 |
| Baseline / kandidat durasi | 4,05 / 3,77 ms | 4,09 / 3,83 ms |
| SQL error baru | Ya | Ya |
| Label otomatis | TP sementara | TP sementara |
| Keputusan validator manusia | pending | pending |

Kedua respons kandidat memuat frasa `You have an error in your SQL syntax` dan `mysqli_sql_exception`, yang tidak muncul pada baseline. HTTP 200 saja tidak menunjukkan keberhasilan atau kegagalan; indikator isi respons menjadi bukti smoke error-based ini.

Payload RAG-off berisi fragmen tautologi dan sintaks yang tidak tersusun sebagai pasangan boolean. Responsnya memunculkan SQL error, tetapi hasil tersebut tidak membuktikan kondisi boolean dieksekusi. Payload RAG-on lebih langsung sesuai quote probe dari korpus pada pasangan ini. Pengamatan satu pasangan tidak cukup untuk menyimpulkan RAG lebih baik.

Budget token tercatat berada di bawah context yang dikonfigurasi: bahkan input ditambah maksimum output masih di bawah 4.096. Durasi kedua generasi tidak dapat digunakan sebagai perbandingan kecepatan RAG karena kondisi load model berbeda.

## Perubahan kode dan verifikasi

- Generator mencatat token aktual, status selesai, dan durasi runtime dari respons Ollama dalam audit.
- `dvwa/smoke_s1_pair.py` memverifikasi form, login, level, kondisi pasangan, dan melakukan satu replikasi per kondisi dengan executor yang sudah ada. Evidence berisi frasa SQL error tetap, bukan halaman penuh. Guard baseline menghentikan smoke bila record normal tidak tampil.
- Tujuh belas unit test lulus, termasuk tiga test baru untuk mencegah penyimpanan informasi di sekitar diagnostik, menjaga nilai field form tidak masuk inventaris, dan menolak baseline yang rusak.
- Guard baseline terakhir diuji dengan fixture setelah smoke nyata; tidak ada pengulangan serangan untuk perubahan tersebut.
- Docker Desktop dinyalakan untuk mengaktifkan lab; container yang sudah dikonfigurasi kembali berjalan. Database tidak di-reset dan tidak dibaca secara langsung. File `sources/` tidak diedit.
