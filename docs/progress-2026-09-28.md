# Catatan milestone lingkungan, 28 September 2026

## Ruang lingkup pemeriksaan

- Target: instance DVWA lokal dalam Docker, hanya melalui tunnel bertoken.
- Klien: runtime Python Google Colab pada notebook
  [`colab_dvwa_smoke.ipynb`](../notebooks/colab_dvwa_smoke.ipynb).
- Pemeriksaan dilakukan melalui antarmuka HTTP DVWA, tanpa akses kode sumber
  target dalam proses pengujian.

| Login DVWA dari sesi Colab | Berhasil |
| Level Low | OK |
| Level Medium | OK |
| Level High | OK |
| Level Impossible | OK |

Output terakhir notebook menampilkan `Milestone koneksi Colab ke empat level
DVWA: TERUJI`. Pemeriksaan dilakukan pada 28 September 2026 sekitar 18.30 WIB.
Level terakhir di sesi notebook adalah Impossible.

Token yang sempat tertulis di editor Colab dicabut dan diganti sebelum uji
berhasil. URL tunnel dan token tidak dicatat di repositori. Tunnel sementara
dihentikan setelah pemeriksaan; jalankan ulang dan ambil URL baru sebelum
eksperimen berikutnya.
